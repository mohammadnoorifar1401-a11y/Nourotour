# نوروتور (NOUROTOUR)

وب‌سایت تک‌صفحه‌ای و راست‌چین آژانس خدمات سفر نوروتور با هدف معرفی تورها، خدمات سفر، محتوای گردشگری و دریافت درخواست مشاوره و رزرو.

## قابلیت‌های تکمیل‌شده

- طراحی واکنش‌گرا برای دسکتاپ و موبایل با رابط فارسی و RTL
- هدر چسبان، منوی موبایل و لوگوی رسمی محلی نوروتور
- بخش هیرو، جست‌وجوی نمایشی، اعتمادسازی و آمار
- فهرست تورها با فیلتر، مرتب‌سازی، جزئیات، علاقه‌مندی و فرم رزرو
- خدمات، گالری، اخبار، مجله سفر، نظرات، درباره ما، FAQ و تماس
- ابزارهای نمایشی تاریخ، ساعت، تقویم، آب‌وهوا و نرخ‌های سفر
- پنل مدیریت محلی با میان‌بر `Ctrl + Shift + A`
- ذخیره تنظیمات، محتوا و علاقه‌مندی‌ها در `localStorage`
- اصلاح دکمه‌های طلایی با گرادیان برند
- ذخیره تمام تصاویر محتوایی و لوگوی اصلی آپلودشده در پوشه `images/`
- تکمیل دارایی‌های تصویری محلی برای جلوگیری از نمایش تصویر شکسته
- بررسی موفق رندر و واکنش‌گرایی در نماهای دسکتاپ و موبایل
- حذف کامل لینک، فیلد مدیریت و منطق جاوااسکریپت اینستاگرام

## مسیرهای قابل استفاده

- `/index.html` یا `/` — صفحه اصلی
- `/#home` — خانه
- `/#tours` — تورها
- `/#services` — خدمات
- `/#gallery` — گالری
- `/#blog` — مجله سفر
- `/#about` — درباره ما
- `/#contact` — تماس و فرم مشاوره
- `/#faq` — پرسش‌های متداول

این پروژه پارامتر URL اختصاصی ندارد. پنل مدیریت از مسیر عمومی جداگانه استفاده نمی‌کند و با میان‌بر صفحه‌کلید باز می‌شود.

## ساختار داده و ذخیره‌سازی

- داده‌های اولیه داخل `index.html` و شیء `defaultData` قرار دارند.
- تنظیمات و داده‌های ویرایش‌شده در مرورگر و در کلید `nourotour_data_v1` ذخیره می‌شوند.
- علاقه‌مندی‌ها در کلید `nourotour_favorites_v1` ذخیره می‌شوند.
- زمان پایان پیشنهاد در کلید `nourotour_offer_end_v1` ذخیره می‌شود.
- هیچ دیتابیس، Table API یا سرویس ذخیره‌سازی سمت سرور استفاده نشده است.
- تصاویر در پوشه محلی `images/` نگهداری می‌شوند.

> پنل مدیریت صرفاً یک ابزار سمت کاربر است و احراز هویت امن یا حفاظت واقعی از داده‌ها فراهم نمی‌کند.

## قابلیت‌های پیاده‌سازی‌نشده

- ارسال واقعی فرم‌های تماس و رزرو به سرور یا CRM
- داده زنده آب‌وهوا، نرخ ارز، ظرفیت و قیمت تورها
- نقشه تعاملی واقعی و اطلاعات قطعی مجوزها
- احراز هویت امن و پنل مدیریت سمت سرور
- پرداخت آنلاین و صدور قرارداد یا واچر

## گام‌های پیشنهادی بعدی

1. جایگزینی اطلاعات تماس، آدرس، مجوزها و قیمت‌های نمونه با داده‌های نهایی.
2. اتصال فرم‌ها به یک سرویس CORS-enabled یا REST API مناسب.
3. اتصال داده‌های تور و محتوا به Table API برای مدیریت پایدار.
4. بهینه‌سازی بیشتر حجم تصاویر برای تحویل سریع‌تر در موبایل.
5. افزودن دامنه و URL عمومی نهایی به متادیتا و مستندات.

## URLهای عمومی و API

- Production: هنوز در این پروژه ثبت یا تأیید نشده است.
- API endpoints: ندارد.
- Canonical تنظیم‌شده در صفحه: `https://noorotour.com/`

## فایل‌های اصلی

- `index.html` — ساختار، استایل‌ها، داده‌ها و رفتار تعاملی سایت
- `images/logo.png` — لوگوی رسمی آپلودشده
- `images/*.jpg` — تصاویر محلی هیرو، تورها، گالری، وبلاگ و سایر بخش‌ها
