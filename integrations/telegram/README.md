# 📱 اتصال فرم‌های سایت به تلگرام

این ماژول به شما کمک می‌کند تا درخواست‌های فرم سفر و مشاوره را **همزمان** به Google Sheets و گروه تلگرام ارسال کنید.

## 🎯 ویژگی‌ها

- ✅ ارسال خودکار درخواست‌ها به گروه تلگرام
- ✅ فرمت زیبا و خوانا با emoji
- ✅ عدم تداخل با سیستم فعلی Google Sheets
- ✅ کار در پس‌زمینه (non-blocking)
- ✅ مدیریت خطا و fallback

## 📦 نصب

### روش ۱: استفاده مستقیم در HTML (پیشنهادی)

فایل `telegram-notifier.js` را از پوشه `integrations` در قسمت انتهای `index.html` قبل از تگ `</body>` اضافه کنید:

```html
<!-- اسکریپت‌های موجود سایت -->
<script>
  // کدهای فعلی سایت که تابع submitLead را دارند
</script>

<!-- اضافه کردن Telegram Notifier -->
<script src="integrations/telegram-notifier.js"></script>

</body>
</html>
```

### روش ۲: استفاده از CDN

می‌توانید فایل را از GitHub مستقیماً لود کنید:

```html
<script src="https://cdn.jsdelivr.net/gh/mohammadnoorifar1401-a11y/Nourotour@main/integrations/telegram-notifier.js"></script>
```

## ⚙️ تنظیمات

### تغییر اطلاعات تلگرام

اگر می‌خواهید توکن ربات یا آیدی گروه را تغییر دهید، فایل `telegram-notifier.js` را ویرایش کنید:

```javascript
const TELEGRAM_CONFIG = {
  botToken: 'YOUR_BOT_TOKEN',  // توکن ربات از @BotFather
  chatId: 'YOUR_CHAT_ID'       // آیدی گروه (با - برای supergroup)
};
```

## 🧪 تست

### تست ۱: باز کردن کنسول مرورگر

1. سایت را باز کنید
2. کنسول مرورگر را باز کنید (F12)
3. باید پیام زیر را ببینید:
   ```
   ✅ Telegram notifier متصل شد
   ```

### تست ۲: ارسال فرم آزمایشی

```javascript
// در کنسول مرورگر این کد را اجرا کنید:
sendToTelegram({
  kind: 'test',
  fullName: 'تست نام',
  phone: '09120000000',
  destination: 'استانبول',
  message: 'این یک تست است',
  createdAtFa: '۱۴۰۳/۰۷/۱۹ ۱۴:۳۰',
  id: 'test-' + Date.now()
});
```

اگر همه چیز درست باشد، پیام در گروه تلگرام شما ظاهر می‌شود.

## 🔧 عیب‌یابی

### پیام‌ها به تلگرام ارسال نمی‌شوند

1. **بررسی اتصال ربات به گروه:**
   - مطمئن شوید ربات عضو گروه است
   - ربات باید دسترسی ارسال پیام داشته باشد

2. **بررسی Console:**
   - اگر خطا دارید، در کنسول مرورگر نمایش داده می‌شود
   - پیام‌های لاگ را بررسی کنید

3. **بررسی توکن و Chat ID:**
   - مطمئن شوید توکن و Chat ID صحیح هستند
   - Chat ID برای supergroup باید با `-100` شروع شود

### تابع submitLead یافت نمی‌شود

اطمینان حاصل کنید که:
- اسکریپت `telegram-notifier.js` **بعد از** اسکریپت‌های اصلی سایت لود می‌شود
- تابع `submitLead` در window تعریف شده است

## 🔒 امنیت

⚠️ **نکته مهم:** توکن ربات تلگرام در کد جاوااسکریپت قرار دارد و برای کاربران قابل مشاهده است.

**راه‌حل‌های امنیتی:**

1. **استفاده از Cloudflare Worker** (پیشنهادی):
   - توکن را در Worker نگه‌داری کنید
   - درخواست‌ها را از طریق Worker ارسال کنید

2. **استفاده از Environment Variables:**
   - توکن را در متغیرهای محیطی قرار دهید
   - در زمان build جایگزین شود

3. **محدود کردن دسترسی ربات:**
   - ربات را فقط در یک گروه خاص استفاده کنید
   - دسترسی‌های اضافی را غیرفعال کنید
