# بکاپ امن MONO — رمزگذاری در مرورگر با قالب NTBK1

این پوشه، بخش رمزگذاری و اندازه‌گیری بکاپ در پنل مدیریت است. هیچ کلیدی در کد نیست
و هیچ داده‌ای برای رمزگذاری به سرور فرستاده نمی‌شود.

| فایل | نقش |
|---|---|
| `core.js` | رمزگذاری/رمزگشایی، gzip، هش، امضای آپلود، اندازه‌گیری — بدون وابستگی |
| `admin.js` | رابط کاربری تب «بکاپ امن» در پنل مدیریت |
| `decrypt.mjs` | بازکردن فایل `.ntbk` روی کامپیوتر (CLI) |
| `test-core.mjs` | تست قالب، دست‌کاری، گذرواژهٔ نادرست و امضا |

## قالب فایل `.ntbk`

```
0..4    "NTBK1"
5       version = 1
6       kdf = 1 (PBKDF2-SHA256)
7       flags (bit0 = gzip)
8..11   iterations (uint32 BE) = 310000
12..27  salt (16 bytes)
28..39  iv (12 bytes)
40..    AES-256-GCM ciphertext (+ 16-byte tag)
```

- کلید: `PBKDF2(passphrase, salt, 310000, SHA-256) → AES-256`
- AAD = ۴۰ بایت سربرگ؛ دست‌کاری هر بایت سربرگ یا بدنه، بازگشایی را شکست می‌دهد
- حجم ثابت افزوده: **۵۶ بایت** (۴۰ سربرگ + ۱۶ تگ)

## محتوای بکاپ

```json
{
  "schema": "nourotour.mono.backup/v1",
  "createdAt": "2026-10-20T…",
  "origin": "https://nourotour.ir",
  "data": { "…": "کل دادهٔ سایت (siteData)" },
  "leads": [],
  "favorites": [],
  "mono": { "fileName": "MONO-v1.7.0-source.zip", "bytes": 289250, "sha256": "…", "base64": "…" }
}
```

## استفاده در پنل

1. پنل را باز کنید (`Ctrl + Shift + A` یا `#admin`).
2. تب **بکاپ امن** → گذرواژه (حداقل ۱۲ نویسه) را دو بار وارد کنید.
3. «ساخت و رمزگذاری بکاپ» → جدول اندازه‌های واقعی نمایش داده می‌شود:
   دادهٔ سایت، درخواست‌ها، سورس MONO، JSON خام، پس از gzip، افزودهٔ رمزگذاری و **حجم نهایی فایل**.
4. «دانلود فایل رمزشده» یا «ارسال به سرور» (با نشانی `https://api.nourotour.ir/v1/backup` و توکن آپلود).

اندازه‌های واقعی اندازه‌گیری‌شده روی همین مخزن:

| حالت | JSON خام | فایل رمزشدهٔ نهایی |
|---|---|---|
| با سورس MONO | ۴۰۳٬۱۳۸ بایت | **۲۸۱٬۲۸۴ بایت** (۲۷۵ کیلوبایت) |
| بدون سورس MONO | ۱۷٬۳۳۴ بایت | **۵٬۵۵۰ بایت** (۵.۴ کیلوبایت) |

## بازیابی

- داخل پنل: تب بکاپ امن → بخش «بررسی و بازیابی بکاپ» → انتخاب فایل `.ntbk` + گذرواژه.
  فایل بررسی می‌شود، سپس می‌توانید JSON را دانلود یا دادهٔ سایت را (با تأیید) بازیابی کنید.
- روی کامپیوتر:

```bash
node integrations/secure-backup/decrypt.mjs nourotour-mono-2026-10-20.ntbk \
  --out backup.json --mono MONO.zip
```

هش سورس MONO پس از استخراج به‌صورت خودکار با مقدار ثبت‌شده مقایسه می‌شود.

## نکات امنیتی

- گذرواژه و توکن آپلود **در localStorage/sessionStorage/کوکی ذخیره نمی‌شوند** و با بستن پنل یا
  تغییر تب از حافظه پاک می‌شوند.
- توکن آپلود پس از هر تلاش ارسال، از فیلد ورودی پاک می‌شود.
- گذرواژهٔ فراموش‌شده قابل بازیابی نیست؛ یک نسخهٔ گذرواژه را در مدیر رمز نگه دارید.
- هیچ کلیدی داخل APK مونو یا این مخزن عمومی نیست. کلیدی که در مرورگر ساخته می‌شود
  فقط در RAM همان تب زندگی می‌کند.
- برای بکاپ‌های بزرگ‌تر از ۱۰ مگابایت، سقف Worker را بالا ببرید یا سورس MONO را جدا کنید.
