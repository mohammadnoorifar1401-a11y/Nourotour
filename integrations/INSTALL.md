# 🚀 راهنمای نصب اتصال تلگرام به سایت نوروتور

این راهنما به شما کمک می‌کند تا فرم‌های سایت را به گروه تلگرام متصل کنید.

## ✅ کارهایی که انجام شده

1. ✅ **ربات تلگرام آماده است:** @nourotour_ir_bot
2. ✅ **ربات به گروه متصل شده:** با موفقیت پیام تست ارسال شد
3. ✅ **فایل‌های ادغام ساخته شده:**
   - `telegram-notifier.js` - ماژول اصلی ارسال به تلگرام
   - `telegram-simple.html` - صفحه تست (برای آزمایش اتصال)
   - مستندات در `telegram/README.md`

## 🧪 مرحله ۱: تست اتصال

قبل از اتصال به سایت اصلی، ابتدا اتصال را تست کنید:

1. فایل `telegram-simple.html` را باز کنید:
   ```
   https://nourotour.ir/integrations/telegram-simple.html
   ```

2. فرم را پر کنید و ارسال کنید
3. بررسی کنید که پیام در گروه تلگرام دریافت شده باشد

اگر پیام دریافت شد ✅، به مرحله بعد بروید.

## 📝 مرحله ۲: اتصال به index.html اصلی

### روش ۱: اضافه کردن یک خط به انتهای فایل (ساده‌ترین)

فایل `index.html` را باز کنید و **قبل از تگ `</body>`** این خط را اضافه کنید:

```html
<!-- اتصال به تلگرام -->
<script src="telegram-integration.js"></script>  <!-- کلاینت رلهٔ سروری -->

</body>
</html>
```

### روش ۲: کپی کردن کد مستقیم

اگر می‌خواهید همه چیز در یک فایل باشد، محتوای `telegram-notifier.js` را کپی کنید و در قسمت `<script>` انتهای index.html قرار دهید:

```html
<script>
// محتوای telegram-notifier.js را اینجا قرار دهید
(function() {
  'use strict';
  // ... کد کامل از telegram-notifier.js
})();
</script>
</body>
</html>
```

### روش ۳: استفاده از CDN

```html
<script src="https://cdn.jsdelivr.net/gh/mohammadnoorifar1401-a11y/Nourotour@main/integrations/telegram-notifier.js"></script>
```

## 🔍 بررسی نصب

بعد از اضافه کردن کد:

1. سایت را در مرورگر باز کنید
2. Console را باز کنید (F12 → Console)
3. باید این پیام را ببینید:
   ```
   ✅ Telegram notifier متصل شد
   ```

اگر این پیام را دیدید، نصب موفقیت‌آمیز بود! ✅

## 🎯 تست نهایی

1. فرم درخواست مشاوره یا رزرو را در سایت پر کنید
2. فرم را ارسال کنید
3. بررسی کنید:
   - ✅ داده‌ها در Google Sheets ذخیره شد
   - ✅ پیام در گروه تلگرام دریافت شد

## 🔧 عیب‌یابی

### پیام "Telegram notifier متصل شد" را نمی‌بینم

**علت:** اسکریپت بارگذاری نشده یا تابع `submitLead` هنوز تعریف نشده.

**راه‌حل:**
1. مطمئن شوید اسکریپت `telegram-notifier.js` **بعد از** تمام اسکریپت‌های دیگر بارگذاری می‌شود
2. بررسی کنید که مسیر فایل درست باشد

### پیام‌ها به تلگرام ارسال نمی‌شوند

**علت 1:** ربات دسترسی ارسال پیام ندارد

**راه‌حل:**
- به گروه تلگرام بروید
- تنظیمات گروه → Administrators
- مطمئن شوید ربات در لیست ادمین‌ها هست یا "All members can send messages" فعال است

**علت 2:** توکن یا Chat ID اشتباه است

**راه‌حل:**
- فایل `telegram-notifier.js` را باز کنید
- بررسی کنید که:
  ```javascript
  const TELEGRAM_CONFIG = {
    botToken: '8898159650:AAEqqUDMSx3BOwzITqvq-a-mrXLI-tWIhNE',  // درست است؟
    chatId: '-1004463990161'  // درست است؟ (با - شروع می‌شود)
  };
  ```

### فرم ارسال می‌شود ولی هیچ پیامی دریافت نمی‌کنم

**راه‌حل:**
1. Console مرورگر را باز کنید (F12)
2. دنبال خطا بگردید
3. اگر خطای CORS دیدید، به روش ۳ (استفاده از Cloudflare Worker) بروید

## 🔐 نکات امنیتی

⚠️ **مهم:** توکن ربات در کد جاوااسکریپت قابل مشاهده است.

**توصیه‌ها:**
1. ربات را **فقط** در یک گروه خصوصی استفاده کنید
2. دسترسی‌های اضافی ربات را غیرفعال کنید
3. برای امنیت بیشتر از Cloudflare Worker استفاده کنید (روش ۳)

## 🌐 روش ۳: استفاده از Cloudflare Worker (امن‌تر)

اگر نگران امنیت توکن هستید، می‌توانیم یک Cloudflare Worker بسازیم که:
- توکن را مخفی نگه می‌دارد
- درخواست‌ها را proxy می‌کند
- امنیت بیشتری دارد

برای فعال‌سازی این روش، به من اطلاع دهید.
