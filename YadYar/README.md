# یادیار (YadYar) — اپلیکیشن شخصی مدیریت اعضا، وظایف و یادآورها

اپلیکیشن اندروید **کاملاً آفلاین** (بدون هیچ دسترسی اینترنتی) برای مرتب‌سازی اطلاعات
مشتری‌ها/پرسنل و آزادسازی ذهن از وظایف. رابط کاربری **Glassmorphism**، ذخیره‌سازی محلی
**SQLite (Room)**، یادآورهای تکرارشونده با نوتیفیکیشن محلی، و بکاپ JSON.

> ✅ هر ۴ مرحله کامل شده است.

---

## استک فنی

| لایه | انتخاب |
|---|---|
| زبان / UI | Kotlin + Jetpack Compose (Material 3) |
| دیتابیس | SQLite با Room — نسخه ۲ با Migration رسمی |
| ناوبری | Navigation-Compose |
| معماری | MVVM سبک + Repository + Manual DI |
| یادآورها | AlarmManager دقیق (setAlarmClock) + WorkManager پشتیبان + BootReceiver |
| بکاپ | kotlinx-serialization (JSON) با SAF (انتخاب فایل) |
| نسخه‌ها | minSdk 26 · targetSdk/compileSdk 35 (روی اندروید ۱۶ اجرا می‌شود) |

## نحوه اجرا

### Android Studio
1. `File → Open` → پوشه `YadYar` → صبر تا Gradle Sync
2. دستگاه (API 26+) یا شبیه‌ساز → **Run ▶**

### خط فرمان
```bash
cd YadYar
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug
```

### گرفتن APK
منوی **Build → Build Bundle(s)/APK(s) → Build APK(s)** یا `./gradlew assembleDebug`

## امکانات کامل

### اعضا (CRUD کامل)
- افزودن / ویرایش / بایگانی (با بازگردانی) / حذف دائمی
- آواتار حرف اول + رنگ قابل انتخاب، نوع مشتری/پرسنل، یادداشت

### فرم مشخصات فرد (همان «فرم مادر») — با افزودن/ویرایش/حذف
برای هر عضو، فرم کامل با این بخش‌ها قابل تکمیل و ویرایش است:
- **هویتی:** نام پدر، کد ملی، سریال کد ملی/کد رهگیری، تاریخ تولد، محل تولد، شماره و سریال شناسنامه
- **تماس و سیم‌کارت:** شماره تماس، اپراتور، پوکه
- **بانکی و کارت:** شماره حساب، شماره کارت، Exp، Cvv2، Pass card، نام کاربری، رمز عبور
- **اعتباری و تسهیلات:** رتبه اعتباری، وضعیت چک، ظرفیت خالی، وام‌های در جریان، وام‌های گرفته‌شده، ضمانت، خطاها

دکمه «پاک کردن مشخصات فرم» فقط فیلدهای فرم را خالی می‌کند (عضو و وظایف می‌مانند).

### وظایف (CRUD کامل)
- افزودن / ویرایش / حذف / تیک انجام
- یادآور: روشن/خاموش · روزانه/هفتگی/ماهانه · ساعت (انتخابگر) · روزهای هفته چندتایی (شنبه..جمعه) · روز ماه ۱..۳۱ (اگر روز نبود → آخر ماه) · یادداشت یادآور
- «خاموش کردن همه یادآوری‌های این عضو» با یک کلیک

### موتور یادآوری (اندروید ۱۳+ / ۱۶)
- **AlarmManager.setAlarmClock** برای اجرای سرِ ساعت (با مجوز `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`)
- اگر یادآور دقیق در دسترس نبود → تنزل به `setExactAndAllowWhileIdle` (کارکرد خراب نمی‌شود)
- **WorkManager دوره‌ای ۱۵ دقیقه‌ای** به‌عنوان تور ایمنی یادآورهای جامانده
- **BootReceiver** — ثبت مجدد همه یادآورها بعد از ری‌استارت
- مجوز **`POST_NOTIFICATIONS`** به‌صورت runtime؛ اگر رد شود فقط نوتیف نمایش داده نمی‌شود
- نوتیفیکیشن شامل عنوان، نام فرد، توضیحات و یادداشت یادآور

### بکاپ (JSON)
- **خروجی:** همه اعضا + مشخصات فرم + وظایف در یک فایل JSON (با تاریخ در نام فایل)
- **بازیابی:** جایگزینی کامل با تأیید قبلی + زمان‌بندی خودکار مجدد یادآورها
- از طریق منوی تنظیمات (⚙ داشبورد)

### صفحه تنظیمات
- بکاپ/بازیابی · وضعیت مجوز اعلان‌ها و یادآور دقیق (با دکمه رفع) · اطلاعات برنامه

## قراردادهای ثابت داده

- **روزهای هفته** `weekDays: [0..6]` → 0=شنبه، 1=یکشنبه، 2=دوشنبه، 3=سه‌شنبه، 4=چهارشنبه، 5=پنجشنبه، 6=جمعه
- **ماهانه:** اگر `dayOfMonth` در ماه جاری نبود (مثلاً ۳۱) → **روز آخر همان ماه**
- `timeHHMM` همیشه رشته `"HH:MM"`

## دیتای نمونه (اولین اجرا)

| عضو | وظایف |
|---|---|
| علی رضایی (مشتری) | «پیگیری سفارش» روزانه **۲ دقیقه بعد** · «تماس هفتگی» خاموش — به‌علاوه فرم مشخصات نمونه |
| سارا احمدی (پرسنل) | «ارسال گزارش ماهانه» **۴ دقیقه بعد** · «بررسی موجودی انبار» |
| مریم محمدی (مشتری) | «پیگیری فاکتور» |

برای تست سریع یادآوری: اپ را باز کنید، ۲ دقیقه صبر کنید → نوتیف «پیگیری سفارش».
